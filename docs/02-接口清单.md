## 认证

```bash
TOK=$(curl -s -X POST http://YOUR_HOST/api/auth/login \
      -H 'Content-Type: application/json' \
      -d '{"password":"<密码>"}' | python3 -c 'import sys,json;print(json.load(sys.stdin)["token"])')
```

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 密码登录，返回 `{"token":"<hex>","expires_in":0}` |

## 设备

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/devices` | 全部设备（含 payload） |
| POST | `/api/devices` | 新增设备。两种方式：① `{"payload":"{...}"}` 导入现成材料；② `{"mode":"generate"}` 现场生成。两者都支持可选 `proxy` 字段（`http(s)://` / `socks5://`），填了则写入 payload，该设备所有请求走它；生成模式下「取 hmac」那一步也走代理 |
| PUT | `/api/devices/{id}` | 编辑。填了 `payload` 走完整校验；只改 `name/status/proxy` 时快速更新 |
| DELETE | `/api/devices/{id}` | 删除 |
| POST | `/api/devices/{id}/check` | 检测登录态，回写 `status` / `nickname` / `xhs_user_id` |
| GET | `/api/devices/material_audit` | **材料一致性体检**（只读）：逐台列出 `problems`，空 = 合格 |
| POST | `/api/devices/{id}/proxy_test` | 代理连通性测试：经代理探测出口 IP，与直连对照 |
| POST | `/api/proxy/test` | **同上，但不依赖设备** —— 供「添加设备」表单预检（设备还没创建时用） |

### 登录态获取（手机号验证码）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/devices/{id}/login/send_code` | 发短信验证码。撞图形验证时返回 `need_captcha` + `picList` / `theme` |
| POST | `/api/devices/{id}/login/captcha` | 单独提交图形验证码（重试场景） |
| POST | `/api/devices/{id}/login/submit` | 一体化登录/注册：`check_code` → 存在则登录，否则注册；成功后回写登录态 |

```bash
# 典型流程
curl -X POST .../api/devices/1/login/send_code -H "Authorization: Bearer $TOK" \
     -H 'Content-Type: application/json' -d '{"phone":"138xxxx","zone":"86"}'
curl -X POST .../api/devices/1/login/submit -H "Authorization: Bearer $TOK" \
     -H 'Content-Type: application/json' -d '{"phone":"138xxxx","zone":"86","code":"123456"}'
curl -X POST .../api/devices/1/check -H "Authorization: Bearer $TOK"
```

## 系统设置

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/settings/tunables` | 读可调参数 |
| POST | `/api/settings/tunables` | 存可调参数 |

当前参数：

```json
{"crawl_num":1,"first_crawl_num":1,"max_per_round":0,
 "push_max_age_minutes":10,"account_switch_minutes":5,"crawl_interval_ms":1000}
```

| 参数 | 含义 |
|---|---|
| `crawl_num` | 每轮抓几个博主 |
| `first_crawl_num` | 首次抓取（新博主）每次抓几页 |
| `max_per_round` | 每轮上限；`0` = 不限 |
| `push_max_age_minutes` | 超过这个时长的旧笔记不推送 |
| `account_switch_minutes` | 账号轮询切换间隔（分钟） |
| `crawl_interval_ms` | 相邻博主抓取间隔（毫秒），**建议 ≥1000** |

## 已移除的接口（2026-10-26）

以下接口属于旧版（代理池 / 抓取引擎 / 游客态），现在**已不可用**（多数 404），不要再用：

```
/api/proxies*            （全部代理池接口）
/api/crawl/*             （抓取状态与日志）
/api/settings/rnote      （RN 客户端配置）
/api/tiny/gen            （iOS 游客设备生成）
/api/devices/clear_exhausted （游客配额清理；实际返回 405——路径被 /api/devices/{device_id} 捕获）
```

> （priv_hex / payload_d / ssk_b64）。见「设备」一节。
